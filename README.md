# Dijital Yoklama gizlilik sayfası

Bu klasör bağımsız bir GitHub reposunun köküne yüklenebilir. Önerilen repo adı `ditijtal-yoklama-gizlilik`.

1. GitHub → New repository → Public. Bu klasördeki index.html, en.html ve account-deletion.html dosyalarını köke yükleyin. Firebase dosyası, anahtar veya katılımcı verisi yüklemeyin.
2. Settings → Pages → Deploy from a branch → main → /(root) → Save.
3. Yayımlanınca adres `https://halilardaculha.github.io/ditijtal-yoklama-gizlilik/` olur. Uygulama mağazalarında bu gerçek çalışan adresi; hesap silme için sonuna account-deletion.html eklenen adresi kullanın.
4. Veri envanteri, amaç/hukuki şart, gerçek saklama ve Firebase yurt dışı aktarım mekanizmasını yayından önce hukuk uzmanıyla doğrulayın. Bir sayfanın yayımlanması tek başına KVKK uyumu sağlamaz. Metin, bu sürümün teknik davranışını açıklar; aktarım sözleşmesi/işletmeci prosedürü tamamlanmış sayılmaz.

Bu çalışma GitHub oturumu açmaz, otomatik repo/politika yayını yapmaz. Yayıncı gerçek URL'yi doğrulamalıdır.
